# OpenAudioOS M0.9

M0.9 is the first RAOP/AirPlay network visibility milestone.

## What it adds

- ESP-IDF Component Manager is enabled again
- `espressif/mdns` dependency
- `_raop._tcp` mDNS advertisement
- RTSP placeholder listener on TCP port 5000
- Logs incoming RTSP requests
- Returns `501 Not Implemented` to clients
- Keeps the M0.8 placeholder audio source for local validation

## What it does not do yet

This is still not a playable AirPlay receiver.

Missing:
- RTSP command implementation
- Apple challenge/response
- RSA/AES key handling
- RTP/UDP audio sockets
- ALAC decoder
- Clock sync
- Metadata
- Volume sync

## Why this matters

If successful, iOS/macOS may see the device as a RAOP target or at least attempt to connect to it. This proves that discovery and TCP session plumbing work before integrating a mature RAOP stack.

## Build note

Do not set `IDF_COMPONENT_MANAGER=0` for M0.9.
