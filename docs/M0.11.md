# OpenAudioOS M0.11

Hotfix for stack overflow when iPhone selects OpenAudioOS as AirPlay output.

## Root cause

The RTSP client task used stack-heavy local buffers and too small a task stack. Real iOS OPTIONS requests triggered a FreeRTOS stack overflow.

## Fix

- RTSP client task stack increased from 6144 to 12288 bytes
- RTSP RX buffer moved from stack to heap
- RTSP response buffer moved from stack to heap
- RTSP RX buffer increased to 4096 bytes
- Response buffer remains bounded
- Version strings in AirPlay logs updated to M0.11

## Test

- Device should no longer reboot
