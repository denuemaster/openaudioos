# OpenAudioOS M0.13

M0.13 adds the AirPlay adapter layer.

## Adds

- `components/oaos_airplay_adapter`
- Adapter status struct
- Source claim/release API
- PCM push API for third-party AirPlay stacks
- `third_party/README`
- AirPlay stack evaluation document

## Why this matters

From now on, a real AirPlay implementation should not call I2S directly.

It should only do this:

```c
oaos_airplay_adapter_claim_source();
oaos_airplay_adapter_push_pcm_s16_stereo(frames, frame_count, timeout_ms);
```

The OpenAudioOS audio engine handles buffering and output.
