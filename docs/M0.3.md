# OpenAudioOS M0.3

M0.3 refactors the monolithic prototype into ESP-IDF components.

## Components

- `oaos_system`
- `oaos_storage`
- `oaos_wifi`
- `oaos_web`
- `oaos_audio`

## Goal

Keep the same behavior as M0.2 while making the architecture suitable for future AirPlay 2, USB Audio and Spotify Connect integration.

## Current data flow

```text
Web UI / API
    ↓
oaos_audio control state
    ↓
test tone source
    ↓
I2S driver
    ↓
PCM5102A
```

## Next milestone

M0.4 should introduce a real PCM ring buffer so future sources such as AirPlay, USB Audio or Spotify can push PCM into the audio engine.
