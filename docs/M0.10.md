# OpenAudioOS M0.10

M0.10 improves discovery credibility.

## Adds

- `_raop._tcp` advertisement
- `_airplay._tcp` advertisement
- More realistic TXT records
- Device ID generated from WiFi MAC
- RTSP listener handles multiple requests per connection
- RTSP `OPTIONS` returns `200 OK`
- Minimal `/info`/`GET`/`GET_PARAMETER` response
- Per-method RTSP counters in `/api/status`

## Still missing

This is not playable AirPlay yet.

Missing:
- Apple challenge/response
- FairPlay/pairing
- ANNOUNCE parsing
- SETUP transport allocation
- RTP/UDP sockets
- ALAC decode
- Timing/clock sync
- Volume and metadata handling
