# OpenAudioOS M0.12

M0.12 handles the first real iOS FairPlay setup request without crashing.

## Observed iOS handshake

```text
OPTIONS * RTSP/1.0
POST /fp-setup RTSP/1.0
```

## Changes

- Adds `/fp-setup` detection in RTSP handler
- Adds `rtsp_fp_setup` counter
- Logs `Content-Length` and first bytes of the FairPlay setup body
- Returns `200 OK` placeholder for `/fp-setup`
- Keeps stack-safe heap-based RTSP buffers from M0.11

## Important

This is still not real FairPlay and not playable AirPlay audio.

The purpose of M0.12 is to observe the next request after `/fp-setup` and prepare for integrating a real reverse-engineered FairPlay/RAOP implementation.
