# OpenAudioOS M0.6

M0.6 introduces the first real audio-engine shape.

## Changes

- Adds PCM ringbuffer
- Splits test tone source from I2S output
- Adds source frame counter
- Adds output frame counter
- Adds ringbuffer used/free stats
- Adds underrun/overrun counters
- Adds future source API: `oaos_audio_push_pcm()`

## Architecture

```text
Test Tone Source
      ↓
oaos_audio_push_pcm()
      ↓
PCM Ring Buffer
      ↓
I2S Output Task
      ↓
PCM5102A
```

## Why this matters

Future protocols such as AirPlay, USB Audio, Spotify Connect, DLNA and Bluetooth should not write directly to I2S. They should push decoded PCM into the audio engine.

That lets OpenAudioOS keep routing, buffering, volume and output drivers independent from streaming protocols.
