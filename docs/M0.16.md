# OpenAudioOS M0.16

M0.16 keeps the internal AirPlay implementation path and improves diagnostics.

## Adds

- RTSP session IDs
- Session request counters
- CSeq tracking
- `/fp-setup` request classification
- `FPLY 3.1.1` detection
- advertised vs actual body-length tracking
- partial body read counter
- `auth_required` state

## Important

M0.16 still does not implement FairPlay key exchange.

The goal is to make the AirPlay handshake deterministic and measurable before adding any cryptographic protocol step.
