# OpenAudioOS M0.14

M0.14 creates the third-party backend integration scaffold.

## Adds

- `oaos_airplay_backend`
- backend status model
- first selected candidate: `rbouteiller/airplay-esp32`
- `tools/fetch_airplay_esp32.sh`
- `third_party/README.md`
- porting guide

## Runtime behavior

Existing M0.13/M0.12 discovery still runs.

The new backend does not replace it yet.

## Why

We need a clean path to reuse mature reverse-engineered AirPlay code without letting third-party code take over the whole firmware architecture.
