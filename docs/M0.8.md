# OpenAudioOS M0.8

M0.8 introduces the AirPlay foundation component.

## Important

This is not real AirPlay/RAOP yet.

It adds:
- `oaos_airplay` component
- AirPlay state machine skeleton
- AirPlay status API
- AirPlay placeholder stream
- Source plumbing into `OAOS_AUDIO_SOURCE_AIRPLAY`

## Test

- Open WebUI
- Click "Start placeholder stream"
- Active source should switch to AirPlay
- You should hear an 880 Hz tone
- Click "Stop placeholder stream"
- Switch source back to Test Tone
