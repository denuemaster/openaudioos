# OpenAudioOS M0.2

Adds a first minimal audio control layer.

## Features

- Start/stop test tone
- Volume control
- Frequency control
- JSON audio state
- Frame counter
- Underrun counter
- Simple web UI controls

## API

- `GET /api/status`
- `GET /api/audio/start`
- `GET /api/audio/stop`
- `GET /api/audio/volume?value=0..100`
- `GET /api/audio/frequency?value=50..20000`
