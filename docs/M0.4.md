# OpenAudioOS M0.4

Production networking cleanup.

## Changes

- Normal mode is STA-only
- Setup AP starts only when no WiFi credentials exist
- mDNS hostname: `openaudioos.local`
- Web UI refresh interval increased to 10 seconds
- Audio task priority reduced slightly
- OTA upload endpoint added

## Important OTA note

The OTA endpoint is included, but the current project still uses the default single-app partition table unless you configure OTA partitions. If no OTA partition exists, the UI/API returns an error. M0.5 should introduce a proper OTA partition table.
