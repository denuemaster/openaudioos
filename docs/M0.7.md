# OpenAudioOS M0.7

M0.7 introduces an audio source abstraction.

## Changes

- Adds `oaos_audio_source_type_t`
- Adds active source state
- Adds source switching API
- Adds source-aware PCM push API
- Test tone becomes the first registered-style source
- Web UI can switch between source IDs
- Placeholder source IDs exist for AirPlay, USB Audio, Spotify, Bluetooth and DLNA

## Architecture

```text
Audio Source
    ↓
oaos_audio_push_pcm_from_source()
    ↓
Active-source gate
    ↓
PCM Ringbuffer
    ↓
I2S Output
    ↓
PCM5102A
```

## Why this matters

AirPlay should not know anything about I2S. It will decode PCM and push frames into the audio engine as `OAOS_AUDIO_SOURCE_AIRPLAY`.

USB Audio, Spotify Connect, Bluetooth and DLNA will follow the same model.
