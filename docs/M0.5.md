# OpenAudioOS M0.5

M0.5 cleans up M0.4 and introduces a proper OTA partition layout.

## Changes

- Removed misleading mDNS URL text from WebUI/API
- Added `partitions.csv` with OTA slots
- Added `sdkconfig.defaults` for custom partition table
- Kept STA-only behavior from M0.4
- Improved OTA status JSON
- WebUI polling reduced to 15 seconds

## OTA

The WebUI accepts an application `.bin` generated by ESP-IDF, usually:

```text
build/OpenAudioOS.bin
```

Do not upload merged flash images to `/ota`.

## Important first flash

Because this release changes the partition table, flash once over USB:

```bash
idf.py -p /dev/cu.usbmodem5C4D0377551 flash monitor
```

After that, OTA updates should be possible through the WebUI.
